> 本文件汇集**发布时必须如实写明**的内容。
> 依据：Codex 第 28/29/33/35 轮裁定 + 本项目实测。
>
> ⚠️ **本文件的存在意义是防止夸大。** 每一项都标了「不能说什么」。

---

## 一、功能是什么

wbapi 内置的**网页登录**：在面板点「添加账号 → 网页登录」，
程序拉起受支持浏览器打开官方登录页，用户正常登录后，程序捕获凭据并落盘。

**无需安装官方 CLI 客户端**（委托方实测确认，2026-10-06）。

---

## 二、🔴 必须如实写明的限制

### 2.1 不得宣称官方集成或服务方认可

> **本工具与上游服务方无任何隶属或授权关系。**
> 使用的是**公开可访问的 OIDC 登录入口**与**实测得到的站点接口**；
> **公开 OIDC ≠ 服务方授权第三方复用 `console` 客户端**。

⚠️ **不能写**：「官方支持」「与官方合作」「官方认证」等任何暗示认可的表述。

### 2.2 验证范围边界

| 项 | 状态 |
|---|---|
| 浏览器启动 / 登录捕获 / 凭据落盘 | ✅ 实测通过 |
| 凭据可独立使用（不依赖浏览器 Cookie）| ✅ 实测通过 |
| 账号归属正确（uid 反查）| ✅ 实测通过 |
| 重启后账号仍可用 | ✅ 实测通过 |
| refresh 续期端点可调用、返回凭据可用 | ✅ 实测通过 |
| **access token 到期后的续期** | ⚠️ **未验证** |
| **offline token 是否有闲置超时** | ⚠️ **未验证**（可能短于 40 天）|
| **`go test -race`** | ⚠️ **本机无 gcc，从未执行** |
| 国际版 workbuddy.ai | ⚠️ 未覆盖 |
| 未覆盖的模型档位、工具调用/取消语义 | ⚠️ 未验证 |

**样本边界**：以上验证均在**同一台机器、同一天、同一网络**完成，
且**只覆盖一个账号的完整"删除→重加"流程**（另有两次登录用不同账号）。
⇒ **不代表**跨天/跨月/闲置后的行为。

### 2.3 自动续期**尚未接入**

> **当前尚未接入自动续期；凭据失效后可能需要重新登录。**

⚠️ 背景（避免误解）：续期端点**已实测可用**（见 `refresh-persistence-result.md`），
但**尚未接进生产代码** —— `Client.TokenRefreshURL()` 目前**零调用方**。
接入是**单独立项**的后续任务，需覆盖：同账号并发续期去重、新 token 原子替换、
失败分类与有限重试；**不能把所有 401/403 都当过期的**；
**不能在已输出流式内容后重放对话**。

### 2.4 额度快照的显示时机

> **登录成功不保证立即有额度快照**；显示 `—` 时**执行一次状态刷新**即可。

⚠️ **不能写**「额度丢失」或「已知必现缺陷」。准确表述：

> 曾观察到登录后额度暂时未知，随后状态查询恢复；
> **发生频率和触发条件尚未确定**。

### 2.5 内存口径（**两个数字都要写**）

> **60 MB 指标约束 wbapi 自身常驻内存。**
> 网页登录需已安装的受支持 Chrome/Edge，并临时启动独立浏览器实例；
> **浏览器内存另计**，登录结束后关闭。

| 对象 | 实测 |
|---|---|
| **wbapi 自身** | **15.75 ~ 16.18 MB**（低于 60 MB 红线）|
| 浏览器进程树 | 约 **920 MB**（12 进程求和，**可能高估**）|

⚠️ **不能只写 16 MB** —— 那会让读者以为"总共只要 16 MB"。
浏览器开销在 8 GB 机器上是**明显的临时资源开销**。

⚠️ 完整测量口径与陷阱见 `docs/panel-dev/memory-measurement.md`
（其中 4.5 节记录了一个**未解释的观察**：曾见到某实例报 70.27 MB，
三条证伪实验都不支持常见解释，**未做代码改动**，待内存压力小时复现）。

### 2.6 CDP 调试端口的残余风险

**登录期间**，CDP 调试端口**对本机其他进程可达且无鉴权**。

已做的缓解：随机端口 + 仅绑回环（启动后**回读**确认）+ 登录互斥 +
用完即杀 + 独立临时 profile + 清理前校验路径。

⚠️ **不能写**「无安全风险」。**不接受此风险的用户可用「导入凭据」方式**
（并列入口永远保留）。

### 2.7 契约稳定性

`/console/login/enterprise`、`/v2/plugin/login/account`、
`/v2/plugin/auth/token/refresh` 都是**实测的站点接口**，
**不是标准 OIDC token endpoint**，**可能随上游变更**。

续期端点**只验证了一种请求形态**（`X-Refresh-Token` 头）；
**其他形态未测试，不承诺兼容**。

## 三、🔴 发布流程要求（避免"改了没生效"）

```powershell
# 1. 用最新源码构建
go build -o wbapi.exe ./cmd/wbapi

# 2. 对**这个 exe** 做验收（不是对源码）
#    改了 internal/app/panel/ 下任何文件都必须重编 —— 面板是 go:embed 的！

# 3. 记录 commit + 构建命令 + exe 哈希
Get-FileHash wbapi.exe -Algorithm SHA256

# 4. 发布**同一份** exe
```

⚠️ **踩过的坑**：改了 `panel/app.js` 但没重编 exe ⇒ 跑的是旧面板，
UI 验收 9 项失败。**编译期不会有任何提示**（见交接文档「七乙」节）。

## 四、🔴 委托方 2026-10-06 提出、**尚未实施**的需求

**「改用用户默认浏览器开新标签页」** —— 委托方已拍板，但明确「先不做」。

⚠️ Codex 第 35 轮裁定：**工程上可接受，但这是新的安全与生命周期边界**，
**不应悄悄混入当前已验收版本**。

**实施时必须逐条满足**（详见 `codex-consult/35-codex-第35轮-裁定.md`）：

- 只附着并监听**应用新建的那个 tab/target**，不扫描其他标签页
- **成功/取消/失败都不关窗口、不结束浏览器进程、不调 `Target.closeTarget`**
- 只 **detach CDP 会话**并停止监听；**标签页由用户自己关**
- **不删除默认 profile**，不清理用户浏览器数据
- 区分「应用拥有的浏览器」与「用户已有浏览器」两个生命周期标志
- **无法附着默认浏览器时明确报错**，不静默退回另一种语义
- 日志**不得出现** token、响应体、无关标签页 URL

**验收至少覆盖**：其他标签页不受影响 / 取消后浏览器仍存活 /
成功后目标标签页仍在 / 用户手动关标签页不会让服务崩溃。

⚠️ **完成前，当前已验收的独立浏览器路径必须保留。**
